About me.

My name is Jyoti Kuppanatti, and I enjoy turning an idea into a well-tested piece of software.

I'm an Automation Test Engineer based in Pune, India, with 13+ years of experience across the full Software Testing Life Cycle (STLC). My focus over the years has sharpened into backend and REST API test automation using Java, Selenium WebDriver, Playwright, Rest Assured, and Cucumber (BDD).

My career started at Tata Consultancy Services (TCS), where I spent twelve years as an Assistant Consultant. I built a hybrid automation framework from scratch there, combining a data-driven design for API testing with the Page Object Model for UI testing, and delivered manual and automation testing across payments, document management, and automotive domains. I led end-to-end test planning, estimation, execution, and reporting to support GO/NO-GO release decisions, and was recognized with a 'Hall of Fame – Spotlight of the Month' award along the way.

From there I moved to Coforge as a Test Specialist, working on REST API testing with Rest Assured and Postman and building Cucumber-based BDD scenarios for payment-processing APIs. Most recently, I was a Test Automation Lead at Deutsche Bank, where I built and led adoption of an end-to-end UI automation framework using Playwright, used WebdriverIO for an employee productivity-tracking application, and verified application changes on GCP-hosted containerized microservices following developer deployments.

I design and build test automation frameworks from scratch using industry-standard patterns — Page Object Model, Data-Driven — and integrate them into CI/CD pipelines with Jenkins, TeamCity, and GitHub Actions. I've also started applying AI coding assistants like Claude CLI and GitHub Copilot to speed up test script generation, debugging, and framework maintenance — it's changed how quickly I can move from an idea to a working test suite.

Beyond pure test automation, I have exposure to cloud-deployed microservices on GCP and to web application security testing fundamentals with Burp Suite. I'm comfortable working in Agile/Scrum environments with Git, JIRA, and Confluence, and I hold an ISTQB Foundation Level certification.

Outside of client work, I keep building: I put together a Playwright automation framework using the Page Object Model, TypeScript, and CI/CD via GitHub Actions, and completed Udemy courses in Full Stack Java Development and web application security testing fundamentals — both aimed at deepening the engineering side of quality engineering.

I'm continuously learning and adapting to new tools and methodologies. My goal is to build reliable, scalable, and high-performance automation frameworks that give teams the confidence to ship. Whether it's designing a framework from the ground up, wiring it into a pipeline, or chasing down a flaky test, I'm passionate about every part of software quality.
